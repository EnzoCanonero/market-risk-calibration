# Market Risk Forecasting

**When does adaptive calibration improve risk forecasts, and when does it mainly regulate recent breach counts?**

A focused study of next-day 5% downside-risk forecasts, comparing rolling calibration with Adaptive Conformal Inference (ACI). Controlled simulations distinguish forecast accuracy from observed coverage; a historical US market application examines the practical trade-offs.
